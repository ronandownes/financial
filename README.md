# Financial Mathematics

A PreTeXt book bringing together finance, accounting, probability, statistics, operations research, optimisation, numerical methods, computing, data analysis and applied projects.

## Structure

- Part I — Finance & Accounting
- Part II — Probability, Statistics & Risk
- Part III — Operations Research & Optimisation
- Part IV — Numerical & Applied Mathematics
- Part V — Computing, Data & Modelling
- Part VI — Applications & Projects

Individual university modules can initially map to chapters, while sections follow the mathematics rather than preserving lecture boundaries.

The main source will live under `source/`. GitHub Pages can be configured later when the HTML build is ready.
